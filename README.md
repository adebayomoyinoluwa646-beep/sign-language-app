# sign_language_app

A new Flutter project for a Nigerian Sign Language recognition Android mobile app.

## Getting Started

This project is an Android mobile app built with Flutter, using the camera and TensorFlow Lite to recognise NSL gestures.

## GitHub APK Builds

The repository includes a GitHub Actions workflow that builds an Android APK on push to `main` or on manual dispatch.

After pushing code to GitHub, open the repository's Actions tab, select the latest run for `Build Flutter APK`, and download the `nsl-app-release` artifact.

This provides a convenient way to host and download the APK directly from GitHub without building locally.
